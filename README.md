echo "# Shift Browser

A shift browsing app build with React 18, TanStack Query TypeScript and CSS grid
 
 ##Features
 - fetch and display shifts from a MOCK rest API
 - filter by specialty and keyword with debouncing
 - apply for shifts with optimistic updates
 - loading skeleton with shimmer animation
 - shift detail modal
 - fully responsive grid layout

 ##Stack
 - React v18
 - TanStack Query v5
 - TypeScript
 - Vite
 - json-server (mock API)

 ##Running locally
 \```bash
 npm install
 npm run dev
 npm run api
 \```
